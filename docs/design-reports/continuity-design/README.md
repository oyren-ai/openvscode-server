# Continuity Design: Surviving a Closed Laptop

Slidev deck reporting on the design/validation effort for keeping coding-agent
sessions alive when a user closes their browser/laptop mid-task (openvscode-server
"surface A" extension-host process chain + the sibling always-on session daemon
"surface B").

Scaffolding in progress — see the tracking PR for the implementation plan.

## Run locally

    cd docs/design-reports/continuity-design
    pnpm install
    pnpm dev
